# Chapter 25 — Afterword

A language model can sound like a mathematician. Lean can check whether a file is a proof. Mathlib can be the floor. A notebook can remember what this machine has seen. None of that is a soul, a department, or a claim of priority.

If this book did its job, you can install the system without folklore, you can choose a command without treating them as synonyms, you can read a status word without translating it into a press release, and you can change the code without breaking the only rule that makes the project worth having:

The model proposes. Lean decides. Mathlib anchors. You remain responsible for meaning.

When you are tired of chapters, run `aimath report` and read the markdown as a stranger. If you would not sign it, do not sign it.

That refusal is the feature.

# Concepts

These essays are short companions. The **full** explanations — including school-level proofs, types, the typecheck dummy, budget arithmetic, and the trust specification — are in the [Reference Book](../book/README.md). Read the book in numbered order if you want the ultimate source. Use these pages when you need one idea in isolation.

**The rule, again.** A language model never decides that something is a theorem. Lean does. Mathlib is the trusted library. Everything else is a hint.

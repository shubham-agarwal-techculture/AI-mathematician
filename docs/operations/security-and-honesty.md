# Security and honesty

## Security

- API keys live in environment variables, not in git.
- Do not expose `serve` on a public interface without a strong token and network controls.
- Untrusted retrieval fetches text; it does not auto-execute foreign Lean as theorems.
- Lowered process priority reduces but does not eliminate resource contention.

## Honesty

- Never present model text as a theorem.
- Never present local novelty as historical discovery.
- Always label relative theorems.
- Disclose AI assistance when publishing or submitting coursework.

# Hobbyist / curious reader guide

You can treat aimath as a serious toy: a way to see what formal proof checking feels like.

## A gentle evening

1. Install following [Getting started](../getting-started.md).
2. Run `aimath resources` and enjoy the machine report.
3. Prove something tiny.
4. Run `aimath curious --steps 1` once and read what it proposed.
5. Skim [Novelty and honesty](../concepts/novelty.md).

## Joy without self-deception

It is delightful when Lean accepts a proof. It is also common for the model to fail. Both outcomes are the system working. The failure cases teach more than the lucky successes.

## Going deeper

When curiosity turns into commitment, graduate to the [Student](student.md) or [Undergraduate](undergrad.md) guides, then the [User manual](../manual.md).
